# How to Publish a Release

1. Go to your GitHub repo → Releases → Draft a new release
2. Tag version: use semantic versioning e.g. v1.1.0
3. Release title: short description e.g. "Chat & DMs Update"
4. Release body: write in markdown. Suggested format:

## ✨ New Features
- Added group chat with Discord-style channels
- Private messaging between members

## 🐛 Bug Fixes  
- Fixed timestamp display in dark mode
- Fixed Reddit cache not clearing correctly

## 🎨 Improvements
- Redesigned settings page
- Improved mobile header layout

5. Click "Publish release"
6. The app will automatically show the What's New modal
   to all users on their next visit.

Tip: use emojis in headers for a friendly look.
The markdown renders directly in the app modal.
